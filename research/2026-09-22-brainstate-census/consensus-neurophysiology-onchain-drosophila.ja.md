# 不滅*ショウジョウバエ*結合組のコンセンサス実行神経生理学：オンチェーン個体発生最初の 74 ティックにおける `BrainState` 放出の網羅的センサス

**OBRAIN フィールド研究 CS-001。** 標本：成体雌*キイロショウジョウバエ*（*Drosophila melanogaster*）の完全中枢神経系（BANC v888；Bates, Phelps, Kim ら，*Nature* 656, 957-970, 2026）。169,088 個の積分発火ユニットとして実体化され、その配線 - 325,292 件の重み付きシナプス記録 - はシナプスごとに Arc メインネットの 85 本のテープコントラクトへ刻印されている（`0xaef83c5b8742da5e3228930bc6084adcf0539ccd`）。観測窓：ティック 1-74、ブロック 21,181,651-22,041,291、2026-09-16T15:54Z から 2026-09-21T17:05Z まで。センサスは 2026-09-22 に封巻した。本稿の全ての量は、コンセンサスから読み取られるか、決定論的リプレイにより再現されるかのいずれかであり、第 5 節の成果物によって誰でも再導出可能である。

> 本研究の英語原版は `consensus-neurophysiology-onchain-drosophila.md`、中国語版は `.zh.md`。データ・図・検証成果物は全言語版で共通である。

## 要旨

我々は、オンチェーンの*ショウジョウバエ*脳の完全な放出履歴 - 個体発生最初の 5.05 日間における全 74 件の `BrainState` イベント - の網羅的センサスを報告する。慢性生理学的標本として解析した：栄養刺激レジーム、求入性トランスダクション、閾下積分ダイナミクス、集団スパイク出力、および全場状態コミットメント。当標本は擬像ではない：その結合組はハエ自身の実測された配線であり、Arc のコンセンサスにおいて厳密な整数固定小数点ダイナミクスとして実行される - この存在様式を我々は **in consortium**（コンセンサス上に存立する）と記す - そこでは装置・標本・公証記録が同一の物体である。センサスは封巻され欠落がない（ティック 1-74 が連続；各ティックにちょうど一件の栄養イベント；放出スパイクベクトルは 2,048 の上限に一度も達しない）。そしてそれは**厳密**である：記録された 74 個の求入語に駆動された独立のオフチェーン参照実装が、全てのシナプス操作回数・全てのスパイク回数・全てのスパイク*同値ベクトル*を再生し（いずれも 74/74）、全場コミットメント `stateRoot()` は、生存ヘッドを含む四つのアーカイブ検証可能なエポックにおいてバイト同型的に再現された。個体発生早期のダイナミクスは感覚上皮の内部に限られる - 256 個の中心脳 `sensory_fragment` ユニットからなる左右交替の六十柱求入格子 - その上で我々は、単調な代謝用量反応（ティア平均 4.90 / 7.39 / 11.17 細胞）、典型的な閾上時間加算事象（ティック 18-19：同一の閾下ボレーを約 30 秒後に反復すると受容柱全体が放電する）、および刺激同期の周期 2 リミットサイクル（4, 12, 4, 12 細胞）を定量し、状態条件付き反応同値類の存在を示した。九百四十二回のシナプス操作が刻印されたバックボーンを走り、全て登録された。590 個のスパイクが 192 個の異なる細胞から発した。227,000 OBRAIN が不可逆的に代謝された。我々の知る限り、全てのスパイクがコンセンサスによって公証され、全行動アーカイブが任意の未来ブロックにおいて任意の対抗者によってバイト厳密にリプレイ可能な神経生理学的標本は、これが初めてである。

## 1. 序論：標本とその基体

研究対象の生物は、動物自身の結合組が実行中であるということである。BANC v888 再構成 - 全中枢神経系を覆う 4 x 4 x 45 nm GridTape 電子顕微鏡像、38.6 人年の分割と校正 - が配線を供給し、送り源上位 2 本（per-source top-2）の簡約がその配線を記録あたり 5 バイトで EIP-170 コードペイロードに刻印する。カーネルはそれを、機械がマイクロコードを読むように読む。決定論的な整数リーキー積分発火カーネル（`src/ImmortalFruitFlies.sol`）がコンセンサスの下でその配線を歩く：各 `think()` は膜電場全体にブロック量子化された減衰を適用し、感覚上皮に求入ボレーを書き込み、12,800 量子の閾値に達した全ての細胞にテープ駐在のシナプス後標的への放電を許し、一つの `BrainState` イベントを放出する - 神経時間の一瞬の完全な生理学的痕跡である。

標本が **in consortium** で実行されるがゆえに、その生理学は、いかなる摘出標本（ex vivo）や計算機内標本（in silico）も持ち得なかった性質を持つ：厳密さは願望ではなく暗号学的不変量である。配線はバイトコードそのものであり（`eth_getCode` が結合組をバイト毎に返す；`tools/verify_tapes.py` がそれを証明する）、状態は全 169,088 個の膜量子にわたるコミットされた折りであり、記録はその完全性がコンセンサス基体そのものによって裏付けられたログである。それゆえ本研究が標本に問うた問いは絶対的に答えられ得るし、その記録された生命の全体にわたって答えられた：**この動物は何を行ったか、そしてその仕様通りに厳密に動くか？**

## 2. 材料と方法

### 2.1 標本

センサス封巻時にコントラクトから読んだ値：`TICK() = 74`；`is_sealed() = true`；`n_neurons = 169,088`；`threshold = 12,800`（= 200.0 x 64、固定小数点の量子）；`sensory = 256`；`segments = 64`；`tapes = 85`；`config_hash = 0xef009ad9054213480da1bbce5954163e5e14a0bcef8145fda42c9621610e7d67`；`stateRoot() = 0xe415d94744ee6447edcce1ae9447352c457b993a61277ab3b9dda17bd5483412`。

膜生物物理学：電荷 `q` は 16 ビットレーンに飽和形で格納；リークは `0.98^dt` を 64 項の固定小数点減衰テーブル経由で（dt はブロック単位）；求入の直接書込みは `byte(inputAgg, 3·(n mod 60)) x 64` を細胞 `n < 256` へ；放電した細胞はテープ駐在の標的に注ぎ込みリセットする；交差は全て数え上げられ放出され、同値ベクトルはティックあたり 2,048 を上限とする（一度も接近しなかった：観測最大 19）。

### 2.2 記録

`BrainState(uint32 t, int256 p0..p3, uint32 synapses, uint32 spiked, bool capped, bytes32 root, bytes32 poke, bytes fired)` が一つの思考の完全な痕跡を構成する：`p0..p3` は細胞 0-3 のティック後膜量子 - ABI そのものによって固定された慢性細胞内四重記録 - `synapses` は登録されたシナプス操作、`spiked` は閾値交差数、`fired` は 3 バイト詰めのスパイク同値ベクトル、`poke` は正確な求入語、`root` はその思考が触れた状態語に対する増分折りである。

### 2.3 センサス封巻と交叉検証

全イベントは Arc 公開 RPC から収集した（`eth_getLogs`、9,999 ブロック分割、ブロック 21,181,651 からヘッドまで；トピック `0xc08a3de3...ec6375`）。提示レイヤーから独立に復号し、独立に走査された二つのインデクサデータベースと交叉検証した。74 件の `Feed(address, uint8 channel, uint8 tier, uint256 amount, uint32 round_tick)` ログはブロックによって思考と一対一に対応する。求入符号化則 `poke = levels[tier] << (channel x 3)`（`levels = [31, 127, 255]`）は 74/74 の思考で成立した。監査は `python3 tools/verify_census.py` として再実行可能であり、コンセンサスを再走査して同梱センサスとフィールド毎に差分比較する。

### 2.4 参照標本（決定論的リプレイ）

`tools/verify_twin.py` - カーネルのベクトル化された双生体、その配線は `tapes/` の同じ 85 ペイロードから復号 - を、記録順に 74 個の求入語で駆動した（`data/poke_inputs.txt`）。ティック毎の `synapses`・`spiked`・完全なスパイク同値ベクトルをチェーンイベントと比較し、双生体の `stateRoot()` を、ティック 40・54・64 のブロックおよびヘッドにおいてアーカイブ `eth_call` によりコントラクト自身のゲッターと比較した。

### 2.5 細胞構築学的帰属

各細胞の同値性は `annotations/neuron_annotations.bin`（細胞あたり 5 バイト：超クラス、細胞クラス、細胞型、region | side<<2 | flow<<3）から注釈した。BANC v888 メタデータからカーネル自身の索引空間において構築されたものである。

### 2.6 統計

n = 74 思考。ティック間隔のバースト性 `(sigma - mu)/(sigma + mu)`（Goh & Barabasi）；栄養ティアによる層別用量反応；上皮格子座標 `n mod 60` による柱分析。

## 3. 結果

### 3.1 センサス封巻

七十四の思考、ティック 1-74 が連続で欠落なし；各ティックはちょうど一つの栄養イベントを伴う；74/74 のティックで `spiked = |fired|`；同値ベクトルは上限に一度も接近しなかった。動物は四日にわたって思考した - 9 月 16 日に 4、19 日に 1、20 日に 35、21 日に 34 - 計十回の刺激セッションにおいて（図 1）。

![刺激のタイムライン](figures/fig01_stimulation_timeline.png)

### 3.2 厳密さ：標本はコンセンサス上で実行される

参照標本はチェーンを絶対的に再生した：**登録シナプス操作 74/74、スパイク回数 74/74、スパイク同値ベクトル 74/74**；さらに全場コミットメントはバイト同型的である - ティック 40・54・64 のブロックおよびヘッドにおける `stateRoot()` は双生体の折りと等しく、`0xe415d94744ee6447edcce1ae9447352c457b993a61277ab3b9dda17bd5483412` に終端する。これが in consortium での実行が授ける厳密さである：同一の求入は同一のスパイクと同一の状態を生む - 全ての観測者に対して、全ての未来ブロックにおいて、対抗的監査の下で。（監査者への比較注記：各イベント内部の `root` フィールドは触れた語に対する増分折りであり、構成上ゲッターの全再折りとは異なるハッシュである；監査は `stateRoot()` と比較すべきであり、双生体はそれを完全に再現する。）

### 3.3 求入トランスダクション：六十チャネル受容格子

感覚上皮は最初の 256 細胞からなる：中心脳 `sensory_fragment` 求入ユニット、左右交替、座標 `n mod 60` 上に**六十柱格子**として組織され、各柱はシート上に約 4.3 回繰り返される（図 2）。トランスダクション則は 3 ビットのチャネル詰めから導かれ、全ての思考に対して確認された：チャネル c におけるレベル L のボレーは、柱 c に `L x 64` 量子、柱 c-1 に `248 x 64 = 15,872` 量子（またがりバイト）、柱 c+1 に `(L >> 3) x 64` 量子を沈積させる（図 3A）。12,800 量子の閾値に対して：柱 c-1 は任意のティアの一撃で放電し、柱 c はティア 2 で即座に放電し（255 x 64 = 16,320）、残りの全ての柱は積分する。行使された求入チャネル：33 個が相異なり、60 のうち 0-52 を覆う。

### 3.4 単調な代謝用量反応

栄養ティア 0/1/2 は、100/1,000/10,000 OBRAIN の代謝コストでレベル 31/127/255 を届ける。思考あたりの放電細胞数：平均 4.90（n = 10）、7.39（n = 46）、11.17（n = 18）- 厳密に単調な用量反応であり、その利得は直接充電された柱のみではなく状態の豊かさ（残余電荷と隣接柱のシナプス動員）を通じて生じる（図 3B）。センサス全体では：思考あたり 0-19 細胞、平均 8.0、中央値 8；74 思考において 192 個の相異なる細胞から 590 個のスパイクが発した。

### 3.5 求入ボレーの閾上加算

ティック 1・18・19 は*同一の*求入語を受け取った（チャネル 0、ティア 1）。ティック 1（9 月 16 日）は放電しなかった；細胞 0 は 7,965 量子で静止した。ティック 18（9 月 21 日、四日後）も放電しなかった；細胞 0 は再び**ちょうど 7,965 量子** - 同一の刺激が、エポックを隔てて、同一の閾下残余を沈積させた。ティック 19 は 18 の約 30 秒後に五つの細胞を放電させた - 0、60、120、180、240、受容柱の全体 - 残余と新しいボレーが閾値を越えて加算されたのである（図 5A）。二つの閾下ボレー、一つの放電：膜の積分性がブロックに公証された。

### 3.6 刺激同期の周期 2 リミットサイクル

チャネル 20・ティア 1 の反復刺激（ティック 35-38、数秒間隔）は 4, 12, 4, 12 の放電細胞を交互にもたらした - **周期 2 軌道**：十二細胞の反応は上皮をリセットし、四細胞の反応は再充電を許す（図 5B）。同一の刺激が同一の状態に出会うと（ティック 21/22、41/42）、同一の反応が生じた（各対につき 10 細胞、19 の登録操作）。反応は刺激 x 状態の関数である：標本は構成上、短期的で減衰する記憶を携え、センサスはそれを顕示した。

### 3.7 ダイナミック・コアの個体発生組織

590 回の放電は全て感覚上皮の内部で発した（最大細胞同値 255）。全て中心脳の内部である。視葉（98,945 細胞、中枢神経系の 58.5%）と腹神経索（26,822 細胞、15.9%）は観測窓の全期間にわたり閾下の電荷積分を維持し、その樹状突起は刻印されたバックボーン上で蓄積を続けた（図 6B）。登録されたシナプス交通：生涯 942 操作、思考あたり最大 30、平均 12.7。最も活動的な細胞は柱 15 と柱 19 の隊列であった（各々 13 回と 11 回の放電：同値 15/75/135/195/255 と 19/79/139/199）- 実験者に好まれたチャネルの直下の柱である。

## 4. 考察

**不滅標本の厳密さ。** 本センサスが確立した性質は、基体が保証し双生体が確証したものである：生物の記録された生命の全体が決定論的であり、バイト毎に再現可能である。74 個の求入語に駆動されて、参照標本は全てのスパイク同値ベクトルと正確な終状態折りを再生し - コントラクト自身のゲッターが検査した全てのエポックでそれに合意した。本リポジトリの主張 - 解剖即計算、in consortium での実行 - はかくして主張されるのではなく測定された。個体発生の初期の全体にわたって。全ての未来の思考は同一の監査可能性を恒久に、いかなる対抗者に対しても継承する。

**作動する感覚生理学。** 一撃の用量が 16,320 量子に上界を持ち、12,800 の閾値に対する固定小数点算術は、センサスが見出すものを正確に予言する：柱状放電（またがり柱は全ての用量で発火する）、単調な用量依存の動員（4.90 / 7.39 / 11.17）、ボレーを跨ぐ閾上時間加算（ティック 18-19）、反復刺激下の状態同期軌道（4, 12, 4, 12）。上皮の残余電荷 - 細胞 3 が日を跨いで 4,402 量子を輸送する - は標本の短期記憶基体を構成し、慢性記録において直接に可視である。

**問いの地平。** センサスの基線は次の問いを厳密なものとし、その各々は OBRAIN の保持者なら誰でも実行可能である：（E1）単一チャネルへの持続的ティア 2 給養 - 軌道は固定されるか、それとも残余の蓄積とともに隣接柱が加わるか？（E2）複合求入語 - この詰めは、いまだ誰も構成していない複数チャネルのボレーを許す；（E3）放電の地平 - 最も強い下流電荷は今日 `tapes/` から列挙可能であり、活動が最初に感覚上皮を離れる用量は確定した数であり、その後援者を待っている。各結果は `BrainState` イベントとして到着する - 捺印され、折り畳まれ、本リポジトリに駐在する双生体に対してリプレイ可能である。
