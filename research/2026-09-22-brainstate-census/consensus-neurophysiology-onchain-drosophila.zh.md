**OBRAIN 田野研究 CS-001。** 标本：成年雌性*黑腹果蝇*（*Drosophila melanogaster*）之完整中枢神经系统（BANC v888；Bates、Phelps、Kim 等，*Nature* 656, 957-970, 2026）， instantiated 为 169,088 个积分-发放单元，其布线 - 325,292 条加权突触记录 - 逐突触刻蚀于 Arc 主网的 85 个 tape 合约之中（`0xaef83c5b8742da5e3228930bc6084adcf0539ccd`）。观察窗口：tick 1-74，区块 21,181,651-22,041,291，2026-09-16T15:54Z 至 2026-09-21T17:05Z。普查于 2026-09-22 封卷；本文之每一个量，或读自共识，或经确定性重放再现，任何一方皆可以第 5 节之工件重新推导。

## 摘要

我们对一枚链上*果蝇*脑的完整发射输出史 - 个体发育最初 5.05 天的全部 74 次 `BrainState` 事件 - 作全量普查，并以慢性生理制备之方式加以分析：营养性刺激模式、传入转导、阈下整合动力学、群体脉冲输出与全场状态承诺。该标本并非拟像：其连接组即果蝇自身被测量出的布线，以精确的整数定点动力学运行于 Arc 共识之中 - 此一存在方式我们记作 **in consortium**（依共识而存）- 其中仪器、制备与公证记录为同一物。普查封卷而无缺隙（tick 1-74 连续；每一 tick 恰有一次营养事件；发射之脉冲向量从未触及 2,048 之上限），且是**精确的**：由 74 个所录传入字驱动的独立链下参考实现，再生了每一次突触操作计数、每一次脉冲计数与每一个脉冲*身份向量*（三项皆为 74/74），而全场承诺 `stateRoot()` 在四个可经档案调用检验的纪元（含活动头块）均逐字节同构再现。个体发育早期的动力学限于感觉上皮之内 - 一张由 256 个中央脑 `sensory_fragment` 单元构成、左右交替的六十柱传入格阵 - 我们在其上量化得：单调的代谢剂量-反应（各档均值 4.90 / 7.39 / 11.17 个细胞）、一次典范性的阈上时间总和事件（tick 18-19：同一阈下传入群相隔约 30 秒重复施加，即令整条感受柱放电），以及一个刺激锁定的周期二极限环（4、12、4、12 个细胞），证实状态条件化的反应等价类之存在。九百四十二次突触操作遍历刻蚀之骨干，皆已登记；590 个脉冲出自 192 个不同细胞；227,000 OBRAIN 被不可逆地代谢。据我们所知，这是第一个每一次脉冲皆由共识公证、且其全部行为档案可在任意未来区块被任何对手方逐字节重放的神经生理学制备。

## 1. 引言：标本及其基底

所研究之生物体，即动物自身的连接组，正在运行。BANC v888 重建 - 覆盖全中枢神经系统之 4 x 4 x 45 nm GridTape 电子显微成像，历经 38.6 人年的分割与校对 - 提供布线；按源取前二（per-source top-2）之约减将该布线以每记录 5 字节刻入 EIP-170 代码载荷，内核读取之，如机器读取微码。一个确定性的整数泄漏积分-发放内核（`src/ImmortalFruitFlies.sol`）随而在共识之下行走该布线：每一次 `think()` 对整个膜电场施加按区块量化的衰减，向感觉上皮写入一个传入脉冲群，允许每一个达到 12,800 量子阈值的细胞向其驻留于 tape 中的突触后目标放电，并发射一个 `BrainState` 事件 - 神经时间之一瞬的完整生理学痕迹。

因为该标本**依共识而存（in consortium）**地运行，其生理学拥有任何离体（ex vivo）或硅内（in silico）制备从未拥有之性质：精确性不是愿望，而是密码学不变量。布线即字节码（`eth_getCode` 逐字节返回连接组；`tools/verify_tapes.py` 证明之）；状态是对全部 169,088 个膜电量子之承诺折叠；记录是一份其完整性由共识基底本身承保的日志。故本研究向该制备提出之问题可被绝对地回答，且贯穿其全部已记录的生命：**此动物做了什么，它是否精确地按其规格运行？**

## 2. 材料与方法

### 2.1 制备

普查封卷时读自合约：`TICK() = 74`；`is_sealed() = true`；`n_neurons = 169,088`；`threshold = 12,800`（= 200.0 x 64，定点量子）；`sensory = 256`；`segments = 64`；`tapes = 85`；`config_hash = 0xef009ad9054213480da1bbce5954163e5e14a0bcef8145fda42c9621610e7d67`；`stateRoot() = 0xe415d94744ee6447edcce1ae9447352c457b993a61277ab3b9dda17bd5483412`。

膜生物物理学：电荷 `q` 以 16 位通道存储，饱和式；泄漏 `0.98^dt` 经由 64 项定点衰减表（dt 以区块计）；传入直写 `byte(inputAgg, 3·(n mod 60)) x 64` 至细胞 `n < 256`；放电细胞倾入驻留于 tape 之目标并复位；每一次越限皆被计数并发射，身份向量以每 tick 2,048 为上限（从未迫近：观测最大值 19）。

### 2.2 记录

`BrainState(uint32 t, int256 p0..p3, uint32 synapses, uint32 spiked, bool capped, bytes32 root, bytes32 poke, bytes fired)` 构成一次思维之完整痕迹：`p0..p3` 为细胞 0-3 在 tick 后之膜电量子 - 一组由 ABI 本身固定的慢性胞内四联记录 - `synapses` 为登记之突触操作，`spiked` 为越限计数，`fired` 为 3 字节打包之脉冲身份向量，`poke` 为确切之传入字，`root` 为对该思维所触及状态字之增量折叠。

### 2.3 普查封卷与交叉验证

全部事件取自 Arc 公共 RPC（`eth_getLogs`，9,999 区块分块，区块 21,181,651 至头块；主题 `0xc08a3de3...ec6375`），独立于任何呈现层解码，并与两份独立游走的索引器数据库交叉验证；74 条 `Feed(address, uint8 channel, uint8 tier, uint256 amount, uint32 round_tick)` 日志按区块与思维一一配对。传入编码律 `poke = levels[tier] << (channel x 3)`（`levels = [31, 127, 255]`）于 74/74 次思维皆成立。该审计可以 `python3 tools/verify_census.py` 重行运行，其重新扫描共识并与所载普查逐字段比对。

### 2.4 参考制备（确定性重放）

`tools/verify_twin.py` - 内核之向量化孪生模型，其布线解码自 `tapes/` 中同一批 85 个载荷 - 按所录顺序由 74 个传入字驱动（`data/poke_inputs.txt`）。我们将逐 tick 之 `synapses`、`spiked` 与完整脉冲身份向量与链上事件比对，并以档案 `eth_call` 在 tick 40、54、64 之区块及头块，将孪生之 `stateRoot()` 与合约自身之 getter 比对。

### 2.5 细胞构筑归属

每一细胞身份标注自 `annotations/neuron_annotations.bin`（每细胞 5 字节：超类、细胞类、细胞型、region | side<<2 | flow<<3），由 BANC v888 元数据在内核自身之索引空间中构造。

### 2.6 统计

n = 74 次思维。tick 间期突发性 `(sigma - mu)/(sigma + mu)`（Goh 与 Barabasi）；按营养档位分层之剂量-反应；以上皮格阵坐标 `n mod 60` 作柱分析。

## 3. 结果

### 3.1 普查封卷

七十四次思维，tick 1-74 连续，无缺隙；每一 tick 恰携一次营养事件；74/74 个 tick 中 `spiked = |fired|`；身份向量从未迫近其上限。该动物于四日间思考 - 9 月 16 日 4 次、19 日 1 次、20 日 35 次、21 日 34 次 - 分十次刺激场次（图 1）。

![刺激时间线](figures/fig01_stimulation_timeline.png)

### 3.2 精确性：标本依共识而运行

参考制备绝对地再生了链：**登记之突触操作 74/74、脉冲计数 74/74、脉冲身份向量 74/74**；且全场承诺逐字节同构 - tick 40、54、64 之区块及头块处之 `stateRoot()` 等于孪生之折叠，终止于 `0xe415d94744ee6447edcce1ae9447352c457b993a61277ab3b9dda17bd5483412`。此即依共识运行所赋予之精确性：相同之传入产生相同之脉冲与相同之状态，对每一观察者、于每一未来区块、经得起对抗性审计。（审计者之比对须知：每一事件内部的 `root` 字段是对所触及字的增量折叠 - 按构造即与 getter 之全量再折叠为不同之哈希；审计应与 `stateRoot()` 比对，而孪生完美再现之。）

### 3.3 传入转导：六十通道感受格阵

感觉上皮由前 256 个细胞组成：中央脑 `sensory_fragment` 传入单元，左右交替，按坐标 `n mod 60` 组织为**六十柱格阵**，每柱在该片上重复约 4.3 次（图 2）。转导律由 3 位通道打包导出，并经每一次思维确证：通道 c 上一个 level-L 之传入群于柱 c 沉积 `L x 64` 量子，于柱 c-1 沉积 `248 x 64 = 15,872` 量子（跨骑字节），于柱 c+1 沉积 `(L >> 3) x 64` 量子（图 3A）。对照 12,800 量子之阈值：柱 c-1 于任意档位之单次传入即放电；柱 c 于档位 2 径直放电（255 x 64 = 16,320）；其余诸柱皆行积分。已行使之传入通道：33 个相异，遍及 60 之 0-52。

### 3.4 单调之代谢剂量-反应

营养档位 0/1/2 以 100/1,000/10,000 OBRAIN 之代谢代价交付 level 31/127/255。每次思维之放电细胞数：均值 4.90（n = 10）、7.39（n = 46）、11.17（n = 18）- 一条严格单调之剂量-反应曲线，其增益源于状态丰度（残余电荷与相邻柱之突触募集），而非仅直接充电之柱（图 3B）。普查全程：每次思维 0-19 个细胞，均值 8.0，中位数 8；74 次思维中 590 个脉冲出自 192 个相异细胞。

### 3.5 传入脉冲群之阈上总和

tick 1、18 与 19 接收到*完全相同*之传入字（通道 0，档位 1）。tick 1（9 月 16 日）未放电；细胞 0 静息于 7,965 量子。tick 18（9 月 21 日，四日之后）未放电；细胞 0 再次处于**恰为 7,965 量子** - 同一刺激，相隔数纪元，沉积同一阈下残余。tick 19，于 18 之后约 30 秒，放电五个细胞 - 0、60、120、180、240，整条感受柱 - 残余与新入脉冲群跨阈值相加（图 5A）。两次阈下传入群，一次放电：膜之积分属性，被公证入区块。

![状态依赖之反应](figures/fig05_state_dependent_responses.png)

### 3.6 刺激锁定之周期二极限环

通道 20 档位 1 之重复刺激（tick 35-38，相隔数秒）交替出现 4、12、4、12 个放电细胞 - 一个**周期二轨道**：十二细胞之反应复位上皮，四细胞之反应容许再充电（图 5B）。相同刺激遭遇相同状态（tick 21/22、41/42）产生相同反应（各对皆为 10 个细胞、19 次登记操作）。反应是刺激 x 状态之函数：标本依构造携有短期、衰减之记忆，而普查将其显明。

### 3.7 动态核心之个体发育组织

全部 590 次放电皆发于感觉上皮之内（最大细胞身份 255），尽在中央脑之内；视叶（98,945 个细胞，占中枢神经系统 58.5%）与腹神经索（26,822 个细胞，15.9%）于整个观察窗口维持阈下电荷积分，其树突于刻蚀骨干之上持续积聚（图 6B）。登记之突触流量：终生 942 次操作，每次思维至多 30，均值 12.7。最活跃之细胞为柱 15 与柱 19 之队列（各放电 13 与 11 次：身份 15/75/135/195/255 与 19/79/139/199）- 即实验者偏好通道之下方诸柱。

## 4. 讨论

**永生标本之精确性。** 本普查所确立者，即基底所保证、孪生所确证之性质：该生物体全部已记录之生命是确定性的、可逐字节再现的。由 74 个传入字驱动，参考制备再生每一个脉冲身份向量与精确之终态折叠 - 而合约自身之 getter 于每一检验纪元皆与之相符。本仓库之主张 - 解剖即计算，依共识而运行 - 由此非被宣称、而是被测量，贯穿个体发育之全程。每一个未来之思维皆承继同一可审计性，直至永久，面对任何对手方。

**一套正在工作之感觉生理学。** 单次传入群之剂量以 16,320 量子为上界、对照 12,800 之阈值，定点算术精确预言普查所见：柱状放电（跨骑柱于每一剂量皆发放）、单调之剂量依赖募集（4.90 / 7.39 / 11.17）、跨传入群之阈上时间总和（tick 18-19）、与重复刺激下之状态锁定轨道（4、12、4、12）。上皮之残余电荷 - 细胞 3 跨日输送 4,402 量子 - 构成标本之短期记忆基底，且于慢性记录中直接可见。

**追问之疆界。** 普查基线令后续诸问题成为精确问题，且每一项皆可由任何 OBRAIN 持有者执行：（E1）单通道持续档位 2 供养 - 轨道是否锁定，抑或残余积聚后相邻诸柱加入？（E2）复合传入字 - 该打包允许尚无实验者构造之多通道传入群；（E3）放电疆界 - 最强之下游电荷今日即可自 `tapes/` 枚举，故活动首度离开感觉上皮所需之剂量是一个确定的数，只待其赞助人。每一结果都将以 `BrainState` 事件抵达 - 加盖、折叠，并可对本仓库所驻之孪生重放。
